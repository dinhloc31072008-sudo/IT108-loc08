# Dự Án Quản Lý Học Tập - PTIT Student Portal

Hệ thống hỗ trợ sinh viên theo dõi tiến độ môn học, quản lý bài tập nhóm và tài liệu học tập tập trung.

---

## 1. Giới thiệu tổng quan
Dự án được xây dựng nhằm giải quyết bài toán đồng bộ dữ liệu và tài liệu học tập giữa các thành viên trong nhóm, tối ưu hóa quy trình làm việc theo chuẩn Git/GitHub.

### Tính năng chính:
- [x] Quản lý thông tin và bài tập theo từng Session.
- [x] Tích hợp tài liệu trực quan chuẩn Markdown.
- [ ] Tự động nhắc hạn nộp bài qua Telegram Bot.

---

## 2. Công nghệ sử dụng
- **Ngôn ngữ**: Python 3.11+
- **Định dạng tài liệu**: Markdown (`.md`)
- **Quản lý phiên bản**: Git & GitHub

---

## 3. Hướng dẫn cài đặt

Chạy lệnh sau trong Terminal để sao chép kho mã nguồn:

```bash
git clone [https://github.com/dinhloc31072008-sudo/IT108-loccc.git](https://github.com/dinhloc31072008-sudo/IT108-loccc.git)
cd IT108-loccc
```
